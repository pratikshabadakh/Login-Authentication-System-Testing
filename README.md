# Login & Authentication System Testing

## Project Overview
This project demonstrates end-to-end manual testing of the Login and Authentication module of a web application. The objective was to validate authentication workflows, identify defects, verify API responses using Postman, and ensure application quality following the Software Testing Life Cycle (STLC).


## Modules Tested

- Login
- Logout
- Forgot Password
- Remember Me
- Session Management
- Authentication API
